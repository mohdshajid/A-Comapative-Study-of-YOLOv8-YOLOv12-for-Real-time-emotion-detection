Emotion detection is a rapidly growing area in
artificial intelligence that enables machines to interpret human
emotional states based on facial expressions. In this paper,
we present the application of YOLO (You Only Look Once)
models—YOLOv8 through YOLOv12—for real-time emotion
detection. Each version brings improvements in architecture,
inference time, accuracy, and robustness. The custom-labelled
emotion dataset includes images classified into emotional states
such as happy, sad, and angry. The system uses these labelled
images for training, and the models are then evaluated based on
performance metrics including mean Average Precision (mAP),
classification accuracy, frames per second (FPS), and memory
efficiency. The best-performing model is recommended based
on specific application requirements. A single neural network
predicts bounding boxes and class probabilities directly from
full images in one evaluation. Since the whole detection pipeline
is a single network, it can be optimized end-to-end directly on
detection performance. Index Terms — YOLO, Deep learning,
